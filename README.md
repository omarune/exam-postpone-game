# 🎮 لعبة "نأجل الامتحان ولا لأ؟"

صفحة ويب تفاعلية مضحكة تجعل المستخدم يحاول الضغط على زر "آه" ولا يستطيع!

## 📁 ملفات المشروع

1. **index.html** - الهيكل الأساسي للصفحة
2. **style.css** - التصميم والأنيميشن
3. **script.js** - المنطق التفاعلي

## 🚀 طريقة التشغيل

### الطريقة 1: فتح مباشر
افتح ملف `index.html` في أي متصفح حديث (Chrome, Firefox, Safari, Edge)

### الطريقة 2: استخدام خادم محلي (اختياري)
```bash
# باستخدام Python
python -m http.server 8000

# أو باستخدام Node.js
npx serve
```

ثم افتح: `http://localhost:8000`

## 🎯 كيفية اللعب

1. **زر "آه" الأخضر**: يهرب منك كلما حاولت الضغط عليه! 🏃‍♂️
2. **زر "لا" الأحمر**: اضغط عليه للاستسلام والحصول على رسالة تشجيعية ❤️
3. **رسائل ساخرة**: تظهر في أماكن عشوائية عند كل محاولة فاشلة 😏
